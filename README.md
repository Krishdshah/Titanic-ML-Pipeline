# Titanic Survival Prediction

Machine Learning project based on the Kaggle Titanic Competition.

## Objective

Predict whether a passenger survived the Titanic disaster using demographic and passenger information.

## Kaggle Dataset
Link: https://www.kaggle.com/competitions/titanic/data

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- CatBoost

## Project Structure

See repository folders for EDA, feature engineering, model training, and submission generation.
